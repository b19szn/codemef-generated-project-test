# Alex Chen — Personal Portfolio Website

A modern, responsive personal portfolio website featuring project showcases, interactive skills grid, animated career timeline, and a functional contact form. Built with vanilla HTML, CSS, and JavaScript — no build step required.

## ✨ Features

- **Hero Section** — Animated stats counters, code snippet visual, performance metric ring, team avatar stack
- **Project Showcase** — Filterable project grid with hover overlays, category tags, and tech stacks
- **Skills Grid** — 16 skills across Design, Engineering, and Leadership with animated progress bars
- **Interactive Timeline** — Career journey with animated markers and highlight tags
- **Contact Form** — Client-side validation, toast notifications, and accessible markup
- **Responsive Design** — Mobile-first, works beautifully from 320px to 1440px+
- **Dark Premium Theme** — Glassmorphism surfaces, ambient glow orbs, calibrated color tokens
- **Micro-interactions** — Hover elevations, button ripple effects, smooth transitions
- **Accessibility** — Semantic HTML, ARIA labels, focus management, reduced motion support

## 🛠 Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, Grid/Flexbox, animations, backdrop-filter
- **Vanilla JavaScript (ES6+)** — IntersectionObserver, IntersectionObserver, form validation, toast system
- **Google Fonts** — Inter + Plus Jakarta Sans
- **No dependencies, no build step**
